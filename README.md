# Ибада — мини-приложение для Telegram (версия 2.2)

Время намазов по геолокации, отметки намазов со статусами (в мечети 150%, джамаатом 120%, совершил 100%, каза 50%, пропущен), сунна и тип дня, тасбих, утренние и вечерние азкары, дуа, Коран с переводом Кулиева, кибла с компасом, календарь хиджры, посты, план восполнения каза, прогресс и серии.

Данные каждого пользователя хранятся в облаке Telegram (CloudStorage) — сервер и база не нужны, приложение сразу подходит любому человеку.

## Файлы

```
index.html        — страница приложения
styles.css        — оформление «Ибада 2.0»: единые цвета, отступы, скругления и размеры текста (тёмная и светлая тема)
app.js            — вся логика
sky.js            — цвет неба, Солнце и Луна (с настоящей фазой) для карточки текущего намаза
data.js           — зикры, азкары, дуа, названия сур
saadi-index.js    — объём чтения по аятам для плана «Тафсир ас-Саади» (без самого текста)
quran/            — арабский текст Корана по сурам (Комплекс короля Фахда, риваят Хафса, версия 18)
fonts/            — шрифт KFGQPC HAFS Uthmanic Script
adhan.min.js — расчёт времени намазов (библиотека adhan, лицензия MIT)
```

## Запуск за 15 минут

### 1. Создайте бота
1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Имя: `Ибада`. Username: любое свободное, оканчивается на `bot`, например `ibada_namaz_bot`.
3. BotFather пришлёт токен. **Никому его не показывайте** — он понадобится на следующем этапе (напоминания).

### 2. Разместите приложение (бесплатно, GitHub Pages)
1. Зарегистрируйте на **github.com** отдельный аккаунт для проекта: нейтральный логин, без настоящего имени и фото.
2. Сразу скройте почту: **Settings → Emails** → включите **Keep my email addresses private** и **Block command line pushes that expose my email**. Делайте это до первой загрузки файлов.
3. Нажмите **New repository** → имя `ibada` → **Public** → **Create repository**.
4. На странице репозитория: **Add file → Upload files** → выберите все файлы из этого архива → **Commit changes**.
5. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/ibada/`. Откройте его в браузере — приложение должно запуститься.

### 3. Привяжите приложение к боту
1. В **@BotFather**: `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button**.
2. Отправьте адрес из шага 2, затем название кнопки: `Открыть`.
3. Там же можно создать прямую ссылку: `/newapp` → выберите бота → название, описание, картинка 640×360 → адрес из шага 2 → короткое имя, например `app`. Ссылка будет `https://t.me/ВАШ_БОТ/app`.
4. Вставьте эту ссылку в начало `app.js` в строку `const SHARE_LINK = '';` — появится кнопка «Поделиться».

Готово: откройте бота в Telegram и нажмите кнопку «Открыть».

## Как обновлять
Замените изменённые файлы через **Add file → Upload files**. Чтобы Telegram не показывал старую версию, увеличьте номер в `index.html`: `app.js?v=1` → `app.js?v=2` (и так же для `styles.css`, `data.js`).

## Приватность
- В коде нет личных данных: ни почты, ни Telegram, ни ссылок на таблицы.
- Никогда не вписывайте в файлы репозитория токен бота, адрес Google-таблицы или пароли — репозиторий открытый. Для следующего этапа они будут храниться в секретных настройках Cloudflare.
- Сайт закрыт от поисковиков (`robots.txt` и метатег `noindex`).

## Что важно знать
- **Время намазов** считается на телефоне по координатам. Метод расчёта и время Асра (стандартное или ханафитское) меняются в разделе «Ещё».
- **Дата хиджры** — по календарю Умм аль-Кура, в настройках можно сдвинуть на день.
- **Коран**: арабский текст и шрифт Комплекса короля Фахда хранятся в самом приложении; перевод смыслов Кулиева загружается из api.alquran.cloud и кешируется на телефоне. Режимы чтения: «Арабский» (по страницам мусхафа), «Перевод», «Тафсир».
- **Тафсир ас-Саади** (перевод Э. Кулиева) загружается по сурам из открытого набора spa5k/tafsir_api (ресурс 36 библиотеки QUL / Tarteel) и сохраняется на телефоне. В репозитории хранится только объём текста по аятам — чтобы пересчитывать аяты в страницы книги и обратно.
- **Поиск города** — через открытый сервис Open-Meteo.
- **Хранение**: в облаке Telegram у каждого пользователя свои данные; 2 записи на месяц, места хватит на десятилетия. Вне Telegram (в браузере) данные сохраняются в браузере.
- **Экран «Сегодня»**: три блока — карточка текущего намаза (живое небо над вашим городом есть только в ней), пять намазов с одной отметкой и «Сегодня ещё» (азкары, план чтения, сунна дня). Недельная цель, план восполнения каза и посты — в «Прогрессе», кибла и календарь — в «Ещё». Режим отметки («Подробно» или «Просто») меняется в «Ещё → Учёт».
- **Азкары перед сном** («Зикр» → «Азкары» → «Перед сном»; ночью — пункт на главной): порядок из Сунны — подготовка (омовение, витр, намерение, постель, правый бок), «Аль-Мульк» и «Аль-Кафирун», аят аль-Курси, конец «Аль-Бакары», три суры с обтиранием, тасбих 33 · 33 · 34 одной кнопкой, 6 мольб и последние слова; режим «Минимум», транскрипция, мольбы при пробуждении. Ночь принадлежит дню, после Иши которого наступила (до Фаджра отметки идут во вчерашний день). Отметки — поле `sl` дня; в итог дня (%) и в таблицу пока не входят. Аяты — из текста мусхафа, мольбы и транскрипция — из документа владельца; перед публикацией сверить со знающим человеком.
- **Цели по Корану** (вкладка «Коран» → «Мои цели»): прочитать весь Коран или выбранные суры — на арабском, в переводе или с тафсиром — либо выучить суры наизусть. Цель считается сурами, целей может быть несколько сразу, срок необязателен. Суры отмечаются в конце суры в читалке или вручную (например, при чтении по бумажному мусхафу). План по сроку распределяется по объёму сур (по числу букв). Выученные суры возвращаются на повторение через 1, 3, 7, 14, 30 и 60 дней; если были ошибки — на следующий день. Данные — ключи `qg` и `hz` в облаке Telegram; в таблицу и бота пока не передаются.
- Арабские тексты азкаров и дуа перед широким распространением стоит сверить со знающим человеком.
