# Сервер бота Ибады

Cloudflare Worker и база D1. Делает три вещи:

- **Присылает напоминания.** О намазах (за 5–30 минут, по времени города или икаме), об утренних, вечерних и вечерних перед сном азкарах, о желательном посте, итог дня. Работает для каждого пользователя, Google-таблица не нужна.
- **Отмечает намазы кнопками в чате.** Ответ мгновенный, через вебхук. Сообщение о намазе одно и меняется: «через 15 мин» → «время, как совершили?» → «✓ отмечено · Изменить».
- **Обменивается отметками с приложением.** Приложение присылает расписание на 2 недели, настройки и два последних дня, а получает отметки, сделанные в боте.

## Как устроено

| Файл | Что внутри |
|---|---|
| `worker.js` | Вебхук `/tg`, обмен с приложением `/api/sync`, настройка бота `/setup`, рассылка каждую минуту (cron) |
| `schema.sql` | Таблицы: пользователи, дни, сообщения о намазах, отправленные напоминания |
| `wrangler.toml` | Имя, cron, адрес приложения, режим `OPEN` (0 — только владелец и `ALLOW`, 1 — все) |
| `test/worker.test.mjs` | Проверки на SQLite и подменённом Telegram: `node --no-warnings bot/test/worker.test.mjs` |

Данные приходят только от проверенных пользователей: подпись Telegram (initData) для приложения, секретный заголовок для вебхука.

## Выкладка

Выкладывает `.github/workflows/bot.yml` при каждом изменении папки `bot/`. Сначала он прогоняет проверки, затем:

1. Создаёт базу.
2. Выкладывает сервер и задаёт секреты.
3. Ставит вебхук, команды, описание и кнопку меню.
4. Записывает адрес сервера в `bot-config.js`.

Секреты репозитория (Settings → Secrets and variables → Actions):

| Секрет | Откуда |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Cloudflare → My Profile → API Tokens → Create Custom Token. Права: Account · Workers Scripts · Edit, Account · D1 · Edit, Account · Account Settings · Read |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare → Workers & Pages, справа «Account ID» |
| `BOT_TOKEN` | @BotFather |
| `OWNER_ID` | Ваш Telegram ID |
| `ALLOW` | Необязательно: ID тестировщиков через запятую |

Пока секретов нет, workflow только прогоняет проверки.

После перехода на этот сервер вебхук отключает опрос `getUpdates` в Google Apps Script. Напоминания из скрипта приложение тоже выключает само. Таблица продолжает получать отметки, как раньше.
